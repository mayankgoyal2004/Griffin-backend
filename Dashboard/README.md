# Griffin Construction — CMS Dashboard

Modern, responsive Content Management System (CMS) & Admin Dashboard for Griffin Construction, built with React 19, Vite, TanStack Router, TanStack Query, Tailwind CSS, and Radix UI.

## Features

- **Dashboard Overview**: Key performance metrics, monthly project statistics, inquiry conversion status charts, and recent activity audit logs.
- **Project Management**: Add, edit, manage, and showcase residential, commercial, industrial, and infrastructure developments.
- **Services Management**: Full control over offered services, icon assignments, detailed scopes, and featured offerings.
- **Inquiry Desk**: Complete lead and customer inquiry pipeline (New, Contacted, In Progress, Converted, Closed) with internal notes and team assignments.
- **Team Management**: Manage executive leadership, architects, and engineering staff profiles.
- **Blog & News CMS**: Rich text editor for construction articles, industry insights, and project announcements.
- **Page Content & SEO**: Customize hero headings, company stats, core advantages, meta descriptions, and OpenGraph assets.
- **Media Library**: In-browser media management with instant drag-and-drop asset uploads.
- **Role-Based Auth**: Administrative and Editor access control.

## Getting Started

### 1. Install dependencies

```bash
cd Dashboard
npm install
```

### 2. Start the development server

```bash
npm run dev
```

The dashboard will be available at `http://localhost:3000`.

### 3. Build for production

```bash
npm run build
```

The optimized static production assets will be generated in `dist/`.
